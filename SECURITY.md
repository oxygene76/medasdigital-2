# Security policy

## Reporting a vulnerability

Please report security issues in medasdigitald or the medasdigital-2 network
privately to **<ADRESSE>**, not in public issues or chats.

Include what you found, how to reproduce it and which version
(`medasdigitald version`) is affected. We confirm receipt and keep you
informed until the issue is fixed. Please give us time to fix the issue and
to coordinate an upgrade with the validators before you publish details.

## Supported versions

Only the version currently running on mainnet (medasdigital-2) receives
security fixes. Fixed advisories of past upgrades are listed in
[docs/upgrades/](docs/upgrades/).

## Dependencies

medasdigitald builds on the Cosmos SDK, CometBFT, ibc-go and CosmWasm
(wasmd, wasmvm). Issues in those components should also be reported to their
maintainers according to their security policies.
